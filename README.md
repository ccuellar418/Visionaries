# Visionaries

Computer Vision Project that we believe is really cool!

## Getting started

1. Install [uv](https://docs.astral.sh/uv/getting-started/installation/) and open a terminal in `Visionaries`. (can run pip install uv or follow linked installation instructions)
2. Run `uv sync` to install dependencies.
3. Start tracking with `uv run python test_hand_tracking`; press `q` to quit.
